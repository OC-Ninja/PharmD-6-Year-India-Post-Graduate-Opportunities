## 📖 About This Project

This is a **free, open-access career analysis resource** built specifically for graduates of the **6-Year PharmD program (India)** — one of the most versatile yet underutilized pharmacy degrees in the country.

Most PharmD graduates don't have a clear picture of the sheer range of opportunities available to them — across clinical practice, pharma industry, regulatory affairs, research, and global careers. This project exists to change that.

Everything here has been **fact-checked and cross-referenced** from official sources including NABP, GPhC, AHPRA, CSIRHRDG, ICMR, Glassdoor India, PayScale, Salary.com, and official regulatory body publications.

## 🔑 Key Facts Verified (Corrections from Common Misconceptions)

| Common Misconception | ✅ Verified Fact |
|---|---|
| CSIR JRF pays ₹31,000/month | **₹37,000/month** (revised Jan 2023) |
| CSIR SRF pays ₹35,000/month | **₹42,000/month** (revised Jan 2023) |
| NAPLEX fee is $700 | **~$620 total** ($520 exam + $100 app) |
| FPGEC fee is ~$520 | **$750** (as of March 2024) |
| FPGEE can be taken from India | **No — only at Pearson VUE in continental USA, once per year** |
| UK route is "just a GPhC OSCE" | **Full OSPAP PG Diploma (1 yr, £14K–£18K) + 52 wks training + Registration Assessment** |
| ICMR JRF is still the exam name | **Renamed BRET (Biomedical Research Eligibility Test) from 2024** |
| Australia registration is simple | **5-step process: APC → KAPS (AUD 2,290) → OPRA → 1,575 hrs → Full registration** |
